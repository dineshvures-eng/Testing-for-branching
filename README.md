# Sample Python snippets

Files:

- `app.py` — launcher to run small examples
- `hello.py` — "Hello, world!"
- `utils.py` — `double()` function
- `greeter.py` — `Greeter` class
- `save_load.py` — JSON read/write example
- `server.py` — tiny static HTTP server (run separately)
- `fetch.py` — simple HTTP client using `requests`

Quick start

1. Run the launcher:

```bash
python app.py
```

2. Install `requests` (for `fetch.py`):

```bash
pip install -r requirements.txt
```

3. Run the HTTP server:

```bash
python server.py
```

That's it — edit and experiment with the examples.
